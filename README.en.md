# soia-open-dev-coding-skills

开发-编码：工程协议、代码审查、缺陷修复、AI 派发（soia-dev-*）

## Domain

This repository owns the `dev` domain. Skill names use the `soia-dev-*` prefix.

## Install

```bash
npx skills add soia-team/soia-open-dev-coding-skills -g -a '*' -s <skill> -y
```

This repository is part of the SOIA skill ecosystem. The canonical specifications live in [soia-team/soia-open-skills](https://github.com/soia-team/soia-open-skills).
